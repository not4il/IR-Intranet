#  IR-Intranet

Some usefull workflow projects to use 

##  How to start

###  Enable Actions Permissions

1. Go to repo **"Settings"**.
2. From the left menu select **"Actions"** → **"General"**.
3. From **"Actions permissions"** select **"Allow all actions and reusable workflows"**.
4. Click **"Save"**.

##  How to use

1. Go to **"Actions"** tab in the repo.
2. From the left menu choose a downloader.
3. Click on **"Run workflow"**.
4. Fill the parameters.
5. Click on **"Run workflow"**.
6. The results will be vivsible after the run is finished in the **"downloads"** folder in the repo.


## Downloaders

1. Web Page Scrapper
2. Telegram File Downloader
4. Direct Link Downloader
5. Youtube Video Downloader
